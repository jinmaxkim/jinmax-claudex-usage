# Claudex Usage

macOS 메뉴 막대에서 Claude와 Codex의 사용량을 한눈에 확인하는 가벼운 로컬 앱입니다. 사용량 비율과 다음 재설정 시점을 표시하며, 필요한 항목만 선택해 추적할 수 있습니다.

## 주요 기능

- Claude의 단기 사용량과 주간 사용량 표시
- Codex 사용량 창별 상태와 재설정 시각 표시
- 사용량 수준에 따라 메뉴 막대 수치 색상 변경
- 메뉴에서 개별 항목 표시 여부 설정
- 수동 새로고침 및 로그인 시 자동 실행 지원
- 별도 서버나 계정 설정 없이 로컬에서 실행

## 요구 사항

- macOS 13 이상
- Swift 컴파일러(`swiftc`)
- Claude 사용량을 표시하려면 Claude 데스크톱 앱
- Codex 사용량을 표시하려면 ChatGPT 앱에 포함된 Codex 실행 파일

## 빌드, 설치 및 실행

저장소를 내려받은 뒤 아래 명령으로 앱을 빌드합니다.

```bash
./build.sh
```

빌드된 앱은 `.build/ClaudexUsage.app`에 생성됩니다. 응용 프로그램 폴더에 설치하려면 다음 명령을 실행합니다.

```bash
./install.sh
```

설치 스크립트는 최신 소스를 빌드한 뒤 `/Applications`에 설치하며, 해당 위치에 쓸 수 없는 경우 사용자 응용 프로그램 폴더에 설치합니다. 설치 후 Finder에서 앱을 열거나 다음처럼 실행할 수 있습니다.

```bash
open -a ClaudexUsage
```

앱은 메뉴 막대 전용 앱이므로 Dock에는 표시되지 않습니다. 메뉴 막대 아이콘을 클릭해 상세 정보, 표시 항목, 자동 실행 설정을 관리할 수 있습니다.

## 빌드 및 배포

개발 중에는 `build.sh`로 앱 번들을 다시 만들고, `install.sh`로 로컬에 설치할 수 있습니다. 배포용 DMG는 다음 명령으로 생성합니다.

```bash
./package.sh
```

생성된 파일은 `dist/` 폴더에 저장됩니다. 배포용 앱은 개발자 인증서로 서명하거나 공증되지 않았을 수 있으므로, 다른 Mac에서는 처음 실행할 때 macOS 보안 안내가 나타날 수 있습니다.

## 데이터와 개인정보

Claude 사용량은 Claude 데스크톱 앱이 로컬에 기록한 사용량 이력 파일을 읽어 표시합니다. Codex 사용량은 로컬 Codex 앱 서버에 조회합니다. 이 앱은 자체 서버로 사용량 데이터를 전송하거나 별도의 네트워크 계정을 요구하지 않습니다.

재설정 시각은 제공되는 사용량 정보와 기록 시점을 바탕으로 계산합니다. 기록 간격이나 원본 데이터 상태에 따라 표시 시각에는 약간의 오차가 있을 수 있습니다.

## 문제 해결

- Claude 값이 보이지 않으면 Claude 데스크톱 앱을 실행한 뒤 사용량 기록이 생성되었는지 확인하세요.
- Codex 값이 보이지 않으면 ChatGPT 앱이 설치되어 있고 Codex를 사용할 수 있는 상태인지 확인하세요.
- 최신 값을 다시 읽으려면 앱 메뉴에서 **지금 새로고침**을 선택하세요.
- 메뉴 막대에서 항목을 숨긴 경우 **추적 항목** 메뉴에서 다시 켤 수 있습니다.
